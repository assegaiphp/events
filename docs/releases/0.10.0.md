# AssegaiPHP Events 0.10.0

Events 0.10.0 aligns the optional framework bridges with the AssegaiPHP 0.10 release line while keeping the event emitter usable as a standalone package.

## Compatibility

- requires PHP 8.4 or newer
- has no direct runtime dependency on `assegaiphp/common` or `assegaiphp/core`
- is the coordinated Events release for AssegaiPHP 0.10 applications
- contains no event runtime behavior changes from Events 0.9

## Upgrade

AssegaiPHP applications should upgrade Events with the coordinated first-party dependencies:

```bash
composer require assegaiphp/events:^0.10 --with-all-dependencies
```

Standalone users can upgrade Events independently because the emitter does not require the framework packages.
