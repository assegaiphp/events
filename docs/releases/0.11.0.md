# Assegai Events 0.11.0

Events joins the coordinated AssegaiPHP 0.11 framework line. This release leaves
the event emitter, listener registration and outbox APIs unchanged.

Standalone use remains supported. Core, Console, ORM and queue integrations stay
optional; installed framework integrations should use their reviewed 0.11
baselines, with queue adapters on the mapped 1.2 line.

Select `assegaiphp/events:~0.11.0` after the coordinated packages are published.
Recheck the optional integrations used by the application when updating them.
